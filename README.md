# Matty's Resume

Simple resume template for Google Docs. To use, click "USE TEMPLATE" [here](https://docs.google.com/document/d/1ySPbahzbSHgs4SDk4r3oAm9JJRg_aN2Dv0wNRXKNq8Y/template/preview)

If it doesn't let you use the template for some reason, you can download the `.docx` file, upload to Google Drive, and open in Google Docs.
